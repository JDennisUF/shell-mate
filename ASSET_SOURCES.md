# Image asset sources

Category and beacon marker icons in `assets/categories/` are copied from the Mortal Shell II map category icons hosted by Gamer Guides:

- Tarstones: `T_UI_Icon_Tarstone_Infusion_Base.png.png`
- Beacons: `mortal_shell_2_beacon.png.png`
- Original Bosses skull: `mortal_shell_2_boss.png.png`
- Dungeons: `mortal_shell_2_dungeon.png.png`
- Rotten Autumn Ghost Beacons: `mortal_shell_2_ghost_beacon.png.png`

Source directory: <https://www.gamerguides.com/images/map-cat-icon/>. Game imagery and trademarks belong to their respective owners.

The displayed Bosses tab icon (`assets/categories/bosses-red-eyes.png`) is a generated edit of the original Bosses skull icon, with a white background, dark skull, and red eyes.
